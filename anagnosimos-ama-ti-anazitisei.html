Αναγνώσιμος άμα τη αναζητήσει

Source note: ELEMENTS/ΚΕΙΜΕΝΑ/Αναγνώσιμος άμα τη αναζητήσει.md

Μικρά πεζά·1 Απριλίου 2021

Απολαμβάνω ιδιαίτερα τη δυνατότητα που μου δίνει το internet να γράφω τις σκέψεις μου σ' αυτό εδώ το blog.

Τις μοιράζομαι με τους ελάχιστους που το έχουν ανακαλύψει.
Μπορώ να διορθώσω κάτι χωρίς να σβήσω ή να μουτζουρώσω (αξία ανεκτίμητη, -μισώ τις μουτζούρες και τις τσαπατσουλιές).
Συγκεντρώνω σε ένα άυλο -και για αυτό άφθαρτο μέσο- όσα γράφω χωρίς να φοβάμαι πως θα χαθούν.
Όλα όσα γράφω παρουσιάζονται καλαίσθητα εδώ.
Έχω πρόσβαση στο περιεχόμενο μου από όλα τα ηλεκτρονικά μέσα.
Μπορώ να συμπληρώνω τα κειμενάκια μου με φωτογραφίες και βίντεο.

Για μένα αυτά εδώ τα λίγα και μικρά κείμενα είναι ο δικός μου ιδιαίτερος θησαυρός που πλέον αντί να κρύβεται σε ένα τετράδιο σε κάποιο συρτάρι, έγινε blog και ταξιδεύει σε όλη τη γη και είναι διαθέσιμο σε όποιον κάνει μια κατάλληλη αναζήτηση. 

Με άλλα λόγια είμαι αναγνώσιμος άμα τη αναζητήσει...

Είναι αυτό που συμβαίνει και στη ζωή.
Καθένας μας συναντά αυτά που αναζητά.
Ή όχι;
